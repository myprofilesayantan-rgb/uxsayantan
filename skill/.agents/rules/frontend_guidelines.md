# Front-end Development Guidelines

- Use **GSAP** (GreenSock Animation Platform) for all animations to achieve smooth, performant, and high-quality motion effects.
- Follow the premium design standards: vibrant color palettes, glassmorphism, micro-animations, and Google Fonts (e.g. Inter).
- Structure HTML semantically, keep CSS modular (prefer CSS variables for theme tokens), and write JavaScript using ES6+ modules.
- Ensure responsiveness and accessibility (ARIA, keyboard navigation).

**Note:** Refer to these guidelines and include GSAP in the animation implementation for all UI sections.
